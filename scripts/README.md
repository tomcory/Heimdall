# Scripts

Tools for checking the VPN and MitM pipeline (`core:vpn`) against real traffic on a rooted
emulator. They run on the development machine and drive the emulator over adb. None of them are part
of the app or of the Gradle build.

| Path | What it does |
|---|---|
| [`emulator-traffic.sh`](emulator-traffic.sh) | Starts the VPN, sends chosen traffic through it (DNS, plain HTTP, raw TCP and UDP, TLS ClientHellos, QUIC Initials, real apps), pulls the database and prints what Heimdall recorded |
| [`quic-initials.txt`](quic-initials.txt) | The QUIC client Initial datagrams that the `quic` group of `emulator-traffic.sh` sends. Generated by `QuicCannedInitialsTest` in `core:vpn`, which also fails if the file is missing or out of date. Synthetic, with `.example` server names |
| [`quic-probe/QuicProbe.java`](quic-probe/QuicProbe.java) | Sends those datagrams from a connected UDP socket on the emulator and reports whether the flow was refused, answered or left without an answer |
| [`stress/run-stress.sh`](stress/run-stress.sh) | Stress test of the VPN: downloads, uploads, slow and aborting peers, parallel connections, UDP and TLS cases. Reports failures, Heimdall's file descriptors, threads and memory, and warnings from logcat. `--baseline` runs the same tests without the VPN |
| [`stress/StressClient.java`](stress/StressClient.java) | The client side of the stress test, run in the emulator's shell so that its traffic passes through the VPN |
| [`stress/stress_server.py`](stress/stress_server.py) | The server side, started on the development machine by `run-stress.sh` (the emulator reaches it as `10.0.2.2`) |
| [`stress/tcp-capture-stats.py`](stress/tcp-capture-stats.py) | Reads a packet capture of the VPN's TUN interface and reports acknowledgement delays, retransmissions and the flags of FIN and RST segments |

## Usage

```bash
scripts/emulator-traffic.sh run [--install] [--quic-policy block|passthrough] [--mitm on|off] \
                                [--block-hosts HOST,HOST] [--tag LABEL] [GROUP...]
scripts/stress/run-stress.sh [--baseline] [TEST[,TEST...]]
```

The groups, tests, environment variables and what each case is expected to show are described in
the comment at the top of each script.

## Requirements

An emulator with Heimdall installed and the VPN consented to once, in the UI or with
`adb shell appops set de.tomcory.heimdall ACTIVATE_VPN allow`; on the development machine `adb`,
`openssl`, `nc`, `xxd`, `sqlite3`, `python3`, a JDK and the Android SDK build tools (`d8`).

Both scripts start, stop and query the VPN, and `emulator-traffic.sh` fetches the database, with
Heimdall's capture commands ([`docs/automation.md`](../docs/automation.md)), which need no root.
Root on the emulator is still needed for decrypted TLS (Heimdall's CA certificate in the system
store) and by `run-stress.sh`, which reads Heimdall's file descriptors and threads.

The scripts start and stop the VPN and force-stop apps, so they refuse a device that is not an
emulator. `emulator-traffic.sh` accepts one anyway with `HEIMDALL_ALLOW_DEVICE=1`; `run-stress.sh`
never does.

To capture an app's traffic for analysis rather than to test the pipeline, use the adb commands in
[`docs/automation.md`](../docs/automation.md).
